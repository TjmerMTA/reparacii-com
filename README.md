# reparatsii.com — «Центр репараційної допомоги»

Статичний сайт на Astro 7. Етап 1: головна сторінка, шапка, підвал.

```bash
npm install
npm run dev      # розробка
npm run build    # збірка в dist/
npm run shots    # скриншоти головної 1440 і 390 px у shots/ (потрібен Google Chrome)
```

## Що замінити перед запуском

Усе в одному файлі — `src/data/site.ts`. Значення в квадратних дужках `[ ... ]` —
заглушки; на сторінці вони підсвічені жовтим пунктиром із позначкою «заглушка».

- `executor`, `contacts`, `prices` — реквізити виконавця, телефон, ціни;
- `reviews` — блок «Відгуки» з’явиться сам, щойно тут буде реальний відгук зі згодою клієнта;
- `form.endpoint` — адреса обробника заявок (TODO у `src/components/Consult.astro`);
- `noindex` — зняти лише після всього переліченого і тексту політики.

Також заглушки: ілюстрація першого екрана (`src/components/HeroArt.astro`), знак
логотипа (`src/components/Logo.astro`), сторінка політики конфіденційності.

## Чого на сайті бути не повинно

Логотипів Ради Європи та RD4U, інтерфейсу Дії на зображеннях, обіцянок виплат,
сум і строків, формулювань «подамо за вас», вигаданих відгуків, заздалегідь
поставленої галочки згоди. Смугу-застереження під першим блоком і блок «Можна
подати самостійно і безкоштовно» не прибирати.
