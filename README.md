# reparatsii.com — «Центр репараційної допомоги»

Статичний сайт на Astro 7: головна і дев’ять сторінок під пошук (інструкція, категорії
A3.3 і A3.6, про Реєстр, документи, питання, ціни, контакти, політика). Українська мова.

```bash
npm install
npm run dev      # розробка
npm run build    # збірка в dist/
npm run check    # перевірка dist: посилання й якорі, H1, title, JSON-LD, robots і sitemap
npm run shots    # скриншоти типових сторінок 1440 і 390 px у shots/ (потрібен Google Chrome)
```

## Що замінити перед запуском

Усе в одному файлі — `src/data/site.ts`. Значення в квадратних дужках `[ ... ]` —
заглушки; на сторінці вони підсвічені жовтим пунктиром із позначкою «заглушка».

- `executor`, `contacts`, `prices` — реквізити виконавця, телефон, ціни;
- `reviews` — блок «Відгуки» з’явиться сам, щойно тут буде реальний відгук зі згодою клієнта;
- `form.endpoint` — адреса обробника заявок (TODO у `src/components/Consult.astro`);
- `noindex` — зняти лише після всього переліченого і тексту політики.

Також заглушки: ілюстрація першого екрана (`src/components/HeroArt.astro`), знак
логотипа (`src/components/Logo.astro`), сторінка політики конфіденційності.

## Чого на сайті бути не повинно

Логотипів Ради Європи та RD4U, інтерфейсу Дії на зображеннях, обіцянок виплат,
сум і строків, формулювань «подамо за вас», вигаданих відгуків, заздалегідь
поставленої галочки згоди. Смугу-застереження під першим блоком і блок «Можна
подати самостійно і безкоштовно» не прибирати.

## Індексація — один прапорець

`noindex` у `src/data/site.ts` керує всім одразу: meta robots на кожній сторінці,
`robots.txt` (закрито → `Disallow: /`) і `sitemap.xml` (закрито → порожній).
Зняти прапорець, поки у файлі даних лишилися заглушки, не вийде: збірка впаде
і перелічить незаповнені поля.

## Факти — лише з першоджерел

Тексти про Реєстр і подання звірено з rd4u.coe.int і diia.gov.ua; перелік джерел —
`src/data/sources.ts`, дата звірки — `VERIFIED` у `src/data/pages.ts`. Чого немає в
першоджерелі, на сайті не пишемо. Після кожної звірки оновлювати `VERIFIED`.

Нова сторінка: файл у `src/pages/` на каркасі `src/layouts/Page.astro` і запис у
`src/data/pages.ts` — звідти беруться меню, хлібні крихти, sitemap і розмітка.
